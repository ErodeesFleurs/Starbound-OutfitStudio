模板、无损编码与估算说明

自动择优比较上游原始、保守小图与双小图的完整衣物指令；明确选择固定模板时不会跨模板。上衣身体与双袖联合计分。保守小图仅替换 RGBA 完全相同的辅助采样；双小图进一步缩小辅助图，但依赖当前模板的透明度处理。

服装与帽子保留精确 RGBA，不减色、不合并动画帧。衣物有界搜索调色板分配、子集与安全排序，保留旧候选，不承诺全局最优；无改进时保留原候选。文本目标比较完整原长，最少遍数关闭调色板后比较原长，两者仅压缩最终赢家以显示估算；压缩目标才逐候选比较完整指令 Deflate。调色板可能增加一次 replace。文本或 Deflate 估算缩减不代表相同的网络收益或 FPS 改善。

PNG 仅在浏览器本地处理，无需上传游戏资产。

衣物动画识别使用原版与 OpenSB 的实测指纹。旧导出的衣物需重新生成并替换，保存在物品中的旧指令不会自动更新。

原身份与安全应用

默认内容仅为可编辑示例，不是你的原角色身份。应用到已有角色前，请用真实 identity 替换；使用示例导出的备份／撤销仅对应示例，不能恢复你的原角色。

02

原版直接改色

RGBA MAPPING

将你提供的原版基底 PNG 与目标 PNG 逐像素配对，联合所有图层生成一段纯 ?replace directives。不需要上传整份 PAK；两张 PNG 都只在浏览器本地由 Rust 解码，不经 Canvas 读回像素。

原图必须对应真正应用的基底与有效帧

请自行从有权使用的原版资源准备实际将应用指令的图层 / 动画帧；原图必须包含指令执行前的真实 RGBA。若还会先执行染色或其它 directives，必须用该阶段的真实结果作原图。本工具不会根据文件名推断物品或自动选取帧。

请覆盖所有将应用同一指令的有效帧与图层，包括攀爬 climb 等动作。精灵表的无效空格应从两图同样裁去，或将有效帧分别裁成配对 PNG；也可先将有效帧按相同顺序合并成两张图。上传整表时，表中每个像素都会参与约束，本工具不会识别或忽略无效格。

人物模式的参考 SVG 含标注、合成参考与共享帧 canonical 布局，不是原版完整精灵表。不要把随意的参考图、SVG 光栅图或 Floran canonical 图视为原版全动作基底。未提供的帧 / 层未经过验证，相同颜色仍会受输出指令影响。

严格完整 RGBA，不是任意位置自绘

同一源 RGBA 必须始终变成同一目标 RGBA，包括保持不变的位置、跨图层重复色、alpha=1 和完全透明像素的隐藏 RGB。若一个源色需要分裂成多个目标色，将显示冲突层与坐标并拒绝生成，不自动 fallback 到其它模式。

alpha=0 的 RGB 虽然预览不可见，仍属于严格匹配条件；不要使用会清零透明 RGB 的编辑器重存原图。本模式使用原图隐藏 RGB，不生成通用自绘模式的透明地址画布，两者不是逐 RGBA 可互换的编码。可以映射 alpha，但将透明色改为可见色可能同时显露所有同源透明像素。

请添加并载入至少一组 PNG；生成时联合检查全部配对。
